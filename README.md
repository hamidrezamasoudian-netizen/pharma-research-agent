# Pharma Research Agent

ایجنت تحقیقات دارویی هوشمند – نسخه تکی با معماری آماده برای ارتقا به مولتی‌ایجنت.

## هدف

شما موضوع تحقیق را از طریق تلگرام ارسال می‌کنید. ایجنت:

1. موضوع را دریافت و تأیید می‌کند
2. تحقیق علمی انجام می‌دهد
3. خروجی‌های زیر را تولید می‌کند:
   - مقاله کامل علمی (DOCX + PDF) با ساختار استاندارد
   - خلاصه اجرایی
   - مایند مپ تصویری
   - خلاصه صوتی فارسی
4. پکیج را برای تأیید شما به تلگرام می‌فرستد

## معماری فعلی (تکی) و آماده برای مولتی‌ایجنت

```
Supervisor (آینده)
│
├── Research Agent      ← نسخه فعلی (این ریپو)
├── Writer Agent
├── Visualizer Agent
├── Audio Agent
└── Reviewer Agent
```

کد فعلی طوری نوشته شده که هر بخش (تحقیق، نگارش، مایند مپ، صوت) به صورت ماژول مستقل باشد تا بعداً بتوان هر کدام را به یک ایجنت جدا تبدیل کرد.

## ساختار پروژه

```
pharma-research-agent/
├── bot.py                  # نقطه ورود تلگرام
├── agent_core.py           # هماهنگی اصلی (نقش Supervisor سبک)
├── research/
│   ├── searcher.py         # جستجوی منابع
│   └── synthesizer.py      # جمع‌بندی و نگارش علمی
├── outputs/
│   ├── document.py         # ساخت DOCX و PDF
│   ├── mindmap.py          # ساخت مایند مپ
│   └── audio.py            # ساخت خلاصه صوتی
├── state/                  # تاریخچه تحقیقات و وضعیت
├── templates/              # قالب‌های مقاله
├── .github/workflows/      # اجرای خودکار (اختیاری)
├── requirements.txt
└── README.md
```

## قابلیت افزودن ایجنت جدید

برای اضافه کردن ایجنت جدید کافی است:
1. یک پوشه/ماژول جدید بسازید
2. آن را در `agent_core.py` ثبت کنید
3. سرپرست (بعد از ارتقا) آن را صدا بزند

## خودکارسازی

بله – می‌توان بخشی از کارها را خودکار کرد:
- اجرای زمان‌بندی‌شده تحقیقات تکراری
- پیگیری موضوعات داغ دارویی
- تولید گزارش هفتگی خودکار
- ذخیره و آرشیو خودکار نتایج

این قابلیت‌ها در فاز بعدی اضافه می‌شوند.
